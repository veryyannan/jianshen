壶铃摇摆
Kettlebell Swing
3组20次/组组间60s
动作步骤
  1. 双脚与肩同宽，脚尖微外展15°，双手握壶铃把手
  2. 髋关节向后推（铰链），膝盖微弯，壶铃在两腿间向后摆
  3. 爆发式挺髋收臀，让壶铃顺势向前摆至肩膀高度
  4. 顶部身体完全伸展：臀、膝、肩成一条直线
  5. 壶铃下落时顺势屈髋蓄力，保持背部平直，循环重复
动作标准
  • 发力点是臀部爆发，手臂只是引导方向，不主动上抬
  • 脊柱全程中立，不弓背塌腰
  • 壶铃摆至肩膀高度即可，不要过头
  • 膝盖不要过度前移，动作是铰链而非深蹲
常见错误
  • 用深蹲替代铰链（膝盖前推而非髋后推）
  • 用手臂力量上抬壶铃，忽略臀部爆发
  • 弓腰圆背，脊柱受伤风险极高

股四头肌·臀部·核心
真人分解图
壶铃深蹲
Goblet Squat
3组20次/组组间60s
动作步骤
  1. 双手捧壶铃底部，置于胸前锁骨下方（杯式握法）
  2. 双脚与肩同宽或略宽，脚尖外展30-45°
  3. 吸气收腹，屈髋屈膝下蹲，膝盖沿脚尖方向推出
  4. 下蹲至大腿平行或低于地面，肘部可轻碰膝盖内侧辅助打开
  5. 呼气蹬地站起，顶部收紧臀部
动作标准
  • 胸部全程挺起，壶铃贴近身体，不要前倾
  • 脚跟全程踩实，重心均匀分布
  • 膝盖不要内扣，与脚尖方向一致
  • 深蹲至大腿平行或更低才算完整动作

真人分解图
单腿罗马尼亚硬拉
Single-leg RDL
3组10次/每腿组间75s
动作步骤
  1. 单手握壶铃（与支撑腿对侧），站立腿微弯，核心收紧
  2. 上身前倾同时后腿向后抬起，保持后腿与躯干一条直线
  3. 壶铃沿支撑腿滑下，感受腘绳肌强烈拉伸
  4. 下放至感觉腘绳肌充分拉伸（约与地面平行）
  5. 以臀部发力将身体拉回直立，左右腿交替完成
动作标准
  • 后腿、骨盆、上身保持同一平面，骨盆不要旋转
  • 支撑腿脚尖朝前，不要外翻
  • 颈椎与脊柱中立，眼看地面斜前方
初学提示
  • 初期手扶墙壁或椅背辅助平衡
  • 先徒手练好姿势再加壶铃

真人分解图
壶铃单臂推举
Single-arm Overhead Press
3组20次/每侧组间60s
动作步骤
  1. 站立，单手将壶铃置于肩膀高度架式位（壶铃靠前臂，肘指前方）
  2. 双脚与肩同宽，收紧核心和臀部，保持身体稳定
  3. 呼气，将壶铃竖直向上推至头顶，手臂伸直锁定
  4. 顶部停顿1秒，感受肩部收缩
  5. 吸气，缓慢控制壶铃回到肩膀位置，重复
动作标准
  • 推举路径垂直，不要偏向身体任何一侧
  • 腰部保持中立，不要过度后仰代偿
  • 非推举侧手叉腰，保持整体平衡
  • 不要用腿部借力（除非做推举变式）

背阔肌·菱形肌·二头
真人分解图
壶铃单臂划船
Single-arm Bent-over Row
3组20次/每侧组间60s
动作步骤
  1. 一手扶凳子或膝盖，对侧手握壶铃自然下垂
  2. 上身与地面约45°，脊柱保持中立，不弓背
  3. 吸气，以背部肌肉发力，将壶铃向腰侧拉起
  4. 肘部向后向上，壶铃拉至腰部，感受背部收缩
  5. 呼气，缓慢放下壶铃，充分伸展背阔肌，重复
动作标准
  • 用背部拉，想象用肘部带动壶铃，而非二头肌
  • 身体不随壶铃旋转，躯干保持稳定
  • 肘部贴近身体，不要外展
  • 下放时2-3秒慢速控制，充分拉伸

腹斜肌·核心抗旋·髋屈肌
真人分解图
壶铃俄罗斯扭转
Kettlebell Russian Twist
3组12-16次/每侧控制节奏
动作步骤
  1. 坐在地面，屈膝，脚跟轻触地面，双手握住小壶铃
  2. 胸口打开，身体微微后倾，核心收紧，保持脊柱中立
  3. 带动胸腔和肩膀向一侧旋转，壶铃跟随身体移动
  4. 回到中间后转向另一侧，左右交替完成
  5. 全程缓慢控制，不要用手臂甩动壶铃
动作标准
  • 旋转来自躯干，不是单纯左右摆手
  • 腰背不弓起，胸口保持打开
  • 壶铃贴近身体，减少腰椎剪切压力
  • 初学者脚跟落地，熟练后可轻抬双脚增加难度
双手持铃
握力·核心·全身张力
真人分解图
农夫行走
Farmer's Walk
3组30秒/组组间60s
动作步骤
  1. 双手各握一个壶铃，自然垂于身侧
  2. 站直，肩胛骨向后收，胸部挺起，深吸气撑住腹腔
  3. 迈步行走，步伐稳健，脚尖朝前，眼睛平视前方
  4. 全程保持挺胸抬头，不要让肩膀下沉
  5. 行走至规定时间，放下壶铃休息
动作标准
  • 肩膀主动保持水平，不随壶铃重量下沉
  • 步伐不要过大，保持稳定节奏
  • 不等重行走可强化核心抗旋转能力
  • 感受手掌握力和前臂全程发力

真人分解图
壶铃负重臀桥
Weighted Glute Bridge
3组15次/组顶部停2秒
动作步骤
  1. 仰卧，双膝弯曲约90°，脚跟距臀部一拳
  2. 将壶铃放在髋骨处，双手握住防止滑落
  3. 呼气发力，臀部向上推至大腿与躯干成一线
  4. 顶部主动夹紧臀部，同时做一次凯格尔收缩，停留2秒
  5. 慢慢放下，臀部不完全落地，维持张力，重复
动作标准
  • 发力点是臀部，腰部不应有任何压力
  • 脚跟踩地发力，不要踮脚尖
  • 顶部夹臀配合凯格尔是功能提升的关键组合
进阶方式
  • 单腿臀桥：一腿伸直，难度与效果翻倍
  • 脚踩高台：增加动作幅度，更深度激活

壶铃单臂前弓步
Single-arm Kettlebell Forward Lunge
3组20次/每侧单侧负重
动作步骤
  1. 单手将壶铃置于肩前架式位，另一手自然伸出保持平衡
  2. 向前迈一步，前脚踩稳，身体保持直立
  3. 下沉至前膝约90°，后膝接近地面但不砸地
  4. 前脚蹬地推回起始位置，左右两侧交替训练
  5. 换手持铃训练另一侧，让核心两侧都得到刺激
动作标准
  • 前膝沿脚尖方向，不内扣
  • 躯干保持垂直，不向持铃侧歪斜
  • 壶铃稳定贴近前臂和肩膀，不要晃动
  • 回推时用前脚发力，不靠后脚弹起
训练价值
  • 单侧负重会加强核心抗侧屈能力
  • 比普通弓步更接近日常走路和运动中的单腿稳定需求

凯格尔运动
内功训练·盆底肌专项·随时随地
无需器材
盆底肌·深层肌群
真人分解图
凯格尔运动
Kegel Exercise
每天2-3次10次/组收5秒放5秒
找到盆底肌
  1. 想象小便中途忍住尿液，收缩的那块肌肉就是盆底肌
  2. 练习时不要真的憋尿，可能引起尿路感染
  3. 收缩时臀部、大腿、腹部不应明显绷紧
  4. 仰卧时更容易感知盆底肌收缩
基础练习
  1. 坐、站、躺均可，放松全身
  2. 收缩盆底肌，保持5秒（初期可从3秒开始）
  3. 完全放松5秒——放松与收缩同样重要
  4. 重复10次为一组，每天2-3组
进阶训练
  • 快速收缩：快速收放，1秒一次，连续10次
  • 电梯式：分层次逐步收紧再逐层放松
  • 配合臀桥：顶部同步凯格尔，效果翻倍

睡眠质量
每晚7-9小时，睾酮主要在深度睡眠中分泌，睡眠不足直接导致激素水平下降。
🥩
营养支持
补充锌（牡蛎、牛肉）和健康脂肪（坚果、鸡蛋），这是合成睾酮的必要原料。
🧘
压力管理
慢性压力使皮质醇升高直接抑制睾酮，每天10分钟冥想或深呼吸效果显著。
🚶
减少久坐
久坐压迫盆腔血管，每小时起身活动5分钟，改善血液循环，配合凯格尔。
⚖️
控制体脂
脂肪中的芳香化酶将睾酮转化为雌激素，维持健康体脂率15-20%是关键。
📈
记录进步
记录每次训练数据，每4周评估进步，适时增重或提升难度，避免停滞期。
